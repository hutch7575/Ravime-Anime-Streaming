# Re;Anime Cast (experimental Android build)
This branch is a standalone Android WebView + local Roku receiver pairing implementation. It is built as an unsigned-for-release, developer-signed debug APK with GitHub Actions. In the app, tap Cast to view the phone Wi-Fi IP and pair code, then install and open the separate Roku receiver. Phone and Roku must be on same Wi-Fi. Test the included public HLS first. Video may fail on Roku if the website requires cookies or unsupported DRM; website login remains on phone. Do not enter credentials into any custom third-party page; the loaded page is https://reanime.to/.
